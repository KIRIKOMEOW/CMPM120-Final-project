**On-Device Testing and Collaboration Evidence**

For on-device testing, we used one team member's demo assignment submission and tested it on a mobile browser.

Demo link:
https://kirikomeow.github.io/CMPM120-Final-project/core-gameplay-1.html

During testing, we found that the prototype worked on desktop but needed clearer touch targets on mobile. The main issue was that the interaction area felt too small on a phone screen, making the player marker and surrounding playfield harder to tap accurately.

To fix this, we created larger, responsive prototype layouts with mobile-friendly spacing and a viewport meta tag so the pages scale correctly in mobile browsers.

Evidence of the fix can be found in the git commit log:
https://github.com/KIRIKOMEOW/CMPM120-Final-project/commits/main
