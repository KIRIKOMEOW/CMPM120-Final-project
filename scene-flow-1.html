CMPM120 Scene Flow Prototype

Bassline Burnout Scene Flow Launcher

Use these cards to jump into the actual prototype pages and Phaser scenes that already exist in this project.

This scene flow prototype links to the actual existing scenes/prototypes in this project, instead of using placeholder mock scenes.

The launcher cards use a simple hover/fade transition, then navigate to real relative URLs such as ./cinematics-prototype/index.html?scene=creditsScene and ./GameplayPrototype/index.html?scene=GameScene.

The current gameplay code uses GameOverScene as its real result scene, so the win and lose buttons launch that existing scene with outcome=win or outcome=lose.

Real Scene / Prototype Links

Main Title Scene Player starts from the Bassline Burnout title and clicks to begin the flow. Opens: cinematics-prototype/index.html?scene=basslineBurnout_Intro Menu / Settings Scene Player reaches the menu, can start gameplay, change settings, or open credits. Opens: cinematics-prototype/index.html?scene=mainMenu Cinematic / Opening Scene After the title interaction, the loading/opening scene leads into the main menu. Opens: cinematics-prototype/index.html?scene=loadingScreen Gameplay Prototype Scene After the cinematic/menu flow, the player enters the rhythm-driving gameplay challenge. Opens: GameplayPrototype/index.html?scene=GameScene Good Ending / Win Result If the player wins the gameplay challenge, the existing result scene opens in win mode. Opens: GameplayPrototype/index.html?scene=GameOverScene&outcome=win Bad Ending / Lose Result If the player loses or crashes, the existing GameOverScene shows the failure result. Opens: GameplayPrototype/index.html?scene=GameOverScene&outcome=lose Credits Scene Credits can be reached directly from the title/menu without finishing the game. Opens: cinematics-prototype/index.html?scene=creditsScene Restart / Back to Title Good Ending, Bad Ending, and Credits can route the player back to the real menu/title flow. Opens: cinematics-prototype/index.html?scene=mainMenu

Scene Flow Map / Documentation

  • Title -> Cinematic / Opening
  • Cinematic / Opening -> Gameplay Prototype
  • Gameplay -> Good Ending if player wins
  • Gameplay -> Bad Ending if player loses
  • Good Ending / Bad Ending -> Credits or Restart
  • Title / Menu -> Credits

Existing Scene Keys Used

  • MenuScene, GameScene, GameOverScene
