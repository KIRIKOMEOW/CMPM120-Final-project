## About

This is the cinematics prototype for **Bassline Burnout**.

Open `index.html` to play it.

## Requirements

- Non-interactive cinematic: the loading scene plays by itself. The text and loading icon fade in, move on screen, and then fade out.
- Interactive cinematic: the title screen and main menu react to the player. The player can click to start. The menu buttons change when the mouse is over them. The Credits button opens the credits scene.
- Choreography in code: `script.js` uses Phaser tweens, camera fades, timed events, and event callbacks to control the scenes.

## Controls

- Click on the title screen to continue.
- Move the mouse over menu buttons.
